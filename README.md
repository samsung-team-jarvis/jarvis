# JARVIS — 온디바이스 스마트 주방 어시스턴트

음성·비전·온도/전류 센서를 Orange Pi(RK3588 NPU)에서 오프라인 융합 추론하고, Safety Guard를 거쳐 ESP32(BLE)로 주방 장비(모형)를 제어한다.
