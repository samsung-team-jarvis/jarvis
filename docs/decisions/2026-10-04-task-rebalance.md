- ②의 기반 작업이 끝났다: 공통 런타임(버스·시뮬레이터·녹화기·런처), 음성 → 명령 서비스(audio_svc·llm_svc), 측정·녹음 도구(bench), LLM 데이터 파이프라인. 남은 ② 작업 중 일부는 **만들어 둔 절차·도구를 실행하는 일**이다.

- 분할 결정의 Revisit 조건: "특정 작업물이 다른 작업물보다 크게 늦어지면 작업 재배분".

## Options
- Option A: 그대로 둔다
- Option B: 실행 위주 7건을 넘긴다 (보드 실행 3건 → ①, 녹음 운영·Hard Negative 검수·대시보드 → ③, 마이크 비교 → ④)
- Option C: B + Seed 검수·`vision_svc`까지 넘긴다

## Decision
- 선택한 안: **B** (결정: 이현종)

| 작업 | 이전 | 이후 | 이유 |
|---|---|---|---|
| BOARD-05 보드 RKLLM 데모 실행 | 이현종 | 신지호 | 보드를 받는 사람이 recipe대로 바로 실행 |
| BOARD-06 Colab RKLLM 변환 실행 | 이현종 | 신지호 | 노트북은 준비됨, 실행만 남음 (① 역할: 노트북 실행) |
